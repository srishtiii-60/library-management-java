# Library Management System (Java)

A console-based Java project to manage library books using OOP concepts.

## Features
- Add a new book
- View all books with status (Available / Issued)
- Issue a book
- Return a book

## Concepts Used
- Classes and objects
- Encapsulation (private fields, getters/setters)
- ArrayList
- Exception handling

## How to run
```
javac Main.java
java Main
```
